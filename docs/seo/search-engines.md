# Search-Engine Registration (Google Search Console & Bing Webmaster Tools)

This runbook documents the exact ownership-verification and sitemap-submission steps for the published documentation site:

- **Property URL (URL prefix):** `https://neurono-ml.github.io/sciencekit-r/`
- **Sitemap URL:** `https://neurono-ml.github.io/sciencekit-r/sitemap.xml`
- **Robots file:** `https://neurono-ml.github.io/sciencekit-r/robots.txt`

No verification tokens are fabricated in this repository. Add the real verification files described below once you obtain them from Google Search Console and Bing Webmaster Tools.

---

## How static verification files work in mdBook

mdBook copies every non-Markdown file under `docs/src/` verbatim to the root of `docs/book/`. When `.github/workflows/deploy-documentation.yml` deploys `docs/book/` to GitHub Pages, any file placed at `docs/src/<filename>` becomes publicly reachable at:

```text
https://neurono-ml.github.io/sciencekit-r/<filename>
```

`docs/scripts/postbuild.mjs` automatically excludes `google*.html` and `BingSiteAuth*` verification files from `sitemap.xml` and leaves their contents untouched so verification byte-matching succeeds.

## 1. Google Search Console

### Step 1.1 — Add the URL-prefix property

1. Open [Google Search Console](https://search.google.com/search-console/welcome).
2. Choose **URL prefix** (not Domain) and enter:
   ```text
   https://neurono-ml.github.io/sciencekit-r/
   ```
3. Click **Continue**.

### Step 1.2 — Verify ownership with an HTML file

1. Under **Verify ownership**, expand **HTML file**.
2. Download the file Google generates — its name has the exact form:
   ```text
   google<16-hex-chars>.html
   ```
   (for example, `google0123456789abcdef.html`, containing the single line `google-site-verification: google0123456789abcdef.html`).
3. Save that exact downloaded file into `docs/src/`:
   ```text
   docs/src/google<token>.html
   ```
4. Commit and push to `docs/documentations` so GitHub Actions deploys it:
   ```sh
   git checkout docs/documentations
   cp ~/Downloads/google<token>.html docs/src/
   git add docs/src/google<token>.html
   git commit -m "docs: add Google Search Console verification file"
   git push origin docs/documentations
   ```
5. Confirm it is live (`HTTP 200`):
   ```sh
   curl -fsSI https://neurono-ml.github.io/sciencekit-r/google<token>.html
   ```
6. Return to Google Search Console and click **Verify**. Do not delete `docs/src/google<token>.html` afterwards; Google re-checks it periodically.

*(Alternative: if you choose the **HTML tag** method instead, paste `<meta name="google-site-verification" content="<token>">` into `docs/theme/head.hbs`.)*

### Step 1.3 — Submit the sitemap

- **In the UI:** Open **Indexing → Sitemaps**, enter `sitemap.xml` next to `https://neurono-ml.github.io/sciencekit-r/`, and click **Submit**.
- **Via the API script:** Obtain an OAuth 2.0 access token with scope `https://www.googleapis.com/auth/webmasters` and run `docs/scripts/submit-sitemaps.sh` (see section 3 below).

## 2. Bing Webmaster Tools

### Step 2.1 — Add the site

1. Open [Bing Webmaster Tools](https://www.bing.com/webmasters).
2. Either **Import from Google Search Console** (fastest once Google Search Console is verified — requires no extra file) or choose **Add manually** with URL:
   ```text
   https://neurono-ml.github.io/sciencekit-r/
   ```

### Step 2.2 — Verify ownership manually (HTML file or XML file)

Bing offers static file verification served from the site root via `docs/src/`:

- **HTML file (`docs/src/<bing-token>.html`):** Download the HTML verification file generated by Bing Webmaster Tools and save it at:
  ```text
  docs/src/<bing-token>.html
  ```
  Once pushed to `docs/documentations`, it is served from the site root at `https://neurono-ml.github.io/sciencekit-r/<bing-token>.html`.
- **XML file (`BingSiteAuth.xml`):** Alternatively, download `BingSiteAuth.xml` from Bing Webmaster Tools and save it at `docs/src/BingSiteAuth.xml` so it serves from `https://neurono-ml.github.io/sciencekit-r/BingSiteAuth.xml`.
- **HTML meta tag:** If using the `<meta>` option instead, add `<meta name="msvalidate.01" content="<token>">` inside `docs/theme/head.hbs`.

Commit and push to `docs/documentations`, verify `HTTP 200` with `curl -fsSI`, then click **Verify** in Bing Webmaster Tools.

### Step 2.3 — Submit the sitemap

- **In the UI:** Open **Sitemaps → Submit sitemap**, enter `https://neurono-ml.github.io/sciencekit-r/sitemap.xml`, and click **Submit**.
- **Via the API script:** Generate an API key under **Settings → API Access → API Key** in Bing Webmaster Tools and pass it as `BING_API_KEY` to `docs/scripts/submit-sitemaps.sh`.

---

## 3. Automated CLI submission (`docs/scripts/submit-sitemaps.sh`)

Once ownership is verified in both consoles, submit `sitemap.xml` programmatically:

```sh
GOOGLE_ACCESS_TOKEN="ya29...." \
BING_API_KEY="<your-bing-api-key>" \
  ./docs/scripts/submit-sitemaps.sh
```

If either `GOOGLE_ACCESS_TOKEN` or `BING_API_KEY` is missing or empty, the script exits immediately with a non-zero status and reports which credential must be supplied.
